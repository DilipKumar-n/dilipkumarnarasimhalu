# Portfolio Website

Responsive and scalable portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- ESLint

## Folder Structure

```txt
src/
  app/
    globals.css
    layout.tsx
    page.tsx
  components/
    common/
      section-heading.tsx
    layout/
      footer.tsx
      header.tsx
    sections/
      about-section.tsx
      contact-section.tsx
      experience-section.tsx
      hero-section.tsx
      projects-section.tsx
      skills-section.tsx
      testimonials-section.tsx
  lib/
    portfolio-data.ts
  types/
    portfolio.ts
```

## Scripts

- `npm run dev` - run local development server
- `npm run lint` - run lint checks
- `npm run build` - create production build
- `npm run start` - start production server

## Run Locally

```bash
npm install
npm run dev
```
